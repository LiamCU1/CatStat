Topic 1: First steps

My goal for this topic is to import the BF data, wrangle it into a tidy format (meaning a format legible to R’s visualization processes), and plot the proportion of cases that tick the various options of our categorical variables.

A note on terminology:

  • Case: The BF database consists of 150+ “cases,” each of which corresponds to a scenario planning study.

  • Field: I use the term “field” to refer to the different variables tracked in the database. Title, year, date contributed, scale(s), and region are fields. I may use this term interchangeably with “variable.”

  • Option: By definition, our categorical fields consist of various options that might apply to a given case. The SDG field has 17 options (for the 17 SDGs), our Region field has 7 options (including non-selection), etc. I refer to a case as “ticking” the options that apply to it. I may use this term interchangeably with “value.”

  • Multiple-select vs single-choice: I refer to fields in which multiple options can be ticked as “multiple-select” fields. Variables for which only one option can be chosen are “single-choice” fields.

Finding the proportions

To find the proportion of cases that tick each variable option, I applied different procedures for the multiple-select and single-choice fields. For the multiple-select variables, the proportions can be found using mean, since they are represented by 0s and 1s. For the single-choice variables, we can use count() and divide by the total number of cases.

When finding the proportions for each field, I had to decide whether to include cases missing data for that field (or NA values) in the total count. I decided not to include NAs for the multiple-select fields, because missing data usually means that the field wasn’t available on the contribution form for that case. True non-selection is represented by 0 instead. For the single-choice fields (specifically region, here, as there are no NAs for contributor role), NA refers to purposeful non-selection, so I decided to include them in the count.

We set our threshold for notable rarity at 5%

For the error bars, I found confidence intervals using the Wilson Score Interval, as implemented in the npsm::wilson.ci() method. Among confidence interval methods that presuppose the binomial distribution1, score interval approaches are best for small datasets. They find the interval by calculating the range of null hypotheses (assumed population proportions) for which the sample proportion would be reasonably likely (i.e. within a determined confidence level). I use the Wilson test specifically because it was suggested in Agresti 2018.

1 the equivalent of the normal distribution for binary data in which individual observations can be assumed to be independent of each other. “Observations,” here, means ticks for a given option between cases. More on this in the Questions section.

# highlight

# field: a string which must be one of the column names defined above
# missing: binary, determines whether function will add a column of 0s for missing values
# shorten: binary, determines whether value names will be shortened in output df
# returns a data frame containing binary-presence data for each 
# value of field per record
occ <- function(bfdat, field, missing = FALSE, shorten = TRUE){
  bf_f <- bfdat |>
    select(id, matches(field))
  names(bf_f)[2] <- "f"
  bf_f <- bf_f |>
    mutate(field_split = strsplit(f, split = "|", fixed = TRUE)) |> #mutate adds another column with the split values
    mutate(f = NULL) |>
    unnest(field_split, keep_empty = TRUE) |> # unnest creates a new row for 
    # each value in the field list
    mutate(value = 1) # this is preparation for the pivot - because I'm looking for 
  # simple binary-presence data, there's no "value" to feed into pivot_wider. 
  # I've appended a column of 1s so that it has at least that
  
  na.ids <- filter(bf_f, is.na(field_split))[["id"]] # Record NA rows for later
  bf_f <- bf_f |> filter_out(is.na(field_split)) |> 
    pivot_wider(names_from = field_split, values_fill = 0)
  
  # Now we'll bring in the value names
  valnm <- import_value_names(field, fields.filenames)
  valnm.og <- valnm[["orig"]]
  valnm.sht <- valnm[["short"]]
  
  bf_fnoid <- bf_f |> mutate(id = NULL)
  valnm.order <- match(valnm.og, names(bf_fnoid))
  
  # Check if there are any possible values not present in the data
  if(NA %in% valnm.order){
    missind <- which(valnm.order %in% NA) # indices of missing values
    missvals <- valnm.og[missind]
    if(missing){
      # add column of 0s
      for(val in missvals){
        bf_fnoid <- bf_fnoid |> mutate("{val}" := 0)
      }
    }else{
      # remove missing value from valnm
      valnm.og <- valnm.og[! missind]
      valnm.sht <- valnm.sht[! missind]
    }
  }
  bf_fnoid <- bf_fnoid[valnm.og] # reorder columns
  
  if(shorten){
    names(bf_fnoid) <- paste0(field, ".", valnm.sht)
  }
  
  bf_fnas <- occ_nas(na.ids, colnames(bf_fnoid))
  
  bf_f <- cbind(bf_f["id"], bf_fnoid)
  bf_f <- rbind(bf_f, bf_fnas) |> arrange(id)
  
  return(bf_f)
}

# highlight

find_multifield_proportions <- function(bfdat, field){
  field.pre <- paste0(field, ".")
  bf.f <- bfdat |> select(starts_with(field.pre))
  # Exclude NAs in count. For any record, any option being NA means all must be
  f1 <- names(bf.f)[1]
  field.n <- bf.f |> filter(!is.na(.data[[f1]])) |> nrow()
  props <- bf.f |> summarise(across(everything(), 
                                    ~mean (.x, na.rm = TRUE)))

  props <- props |> pivot_longer(starts_with(field.pre), names_to = "option", 
                                 names_prefix = field.pre, values_to = "prop") |>
    mutate(field = field, .before = option) |> 
    mutate(n = field.n, .before = option)

  return(props)
}

find_prop_CI <- function(bfprops, conf){
  bfprops <- bfprops |> mutate(ct = prop * n) |> 
    rowwise() |> mutate(ci = list(wilson.ci(ct, n, conf.level = conf)), 
                        ci.low = ci[[1]], ci.hi = ci[[2]]) |>
    mutate(ct = NULL, ci = NULL)
  return(bfprops)
}

My goal for this topic is to perform independence tests, calculate residuals, and make mosaic plots for both my single-choice and multiple-response data.

Another note on terminology: in their text about the MRCV (multiple-response categorical variables) R package, Koziol and Bilder (2014) use the word “item” to describe the options within a multiple-response variable. I will adopt that language from now.

What I did

What happens when we look at the multiple-response variables?

The MRCV (multiple response categorical variables) package enables independence tests on multiple-response data by creating larger contingency tables (in which each cell becomes a 2x2 table, relating the presence/absence of the row item to the presence/absence of the column item) and adapting the basic statistical tests to account for the extra complexity. Normal independence tests do not apply to multiple-response data because these tests do not account for the dependencies that likely exist within variables in MRCV data.

For now, I’ll use their Rao-Scott adjustment, since I think our dataset is too small for bootstrapping to be the best option.

years_to_decades <- function(years){
  decade.levels <- c("2000s", "2010s", "2020s")
  d.breaks <- c(2000, 2010, 2020, 2030)

  decades <- years |> as.numeric() |> 
    cut(breaks = d.breaks, labels = decade.levels, right = FALSE)

  return(decades)
}

  xformula <- as.formula(paste("~", vformula))
  return(xtabs(xformula, bfdata))
}

# outputs: an object, the output of a chi squared test
singles_x2_test <- function(bfdata, vars){
  xt <- singles_contingency2(bfdata, vars)
  return(chisq.test(xt))
}

# outputs: a plot object, giving a mosaic test with the specifications given below
singles_mosaic <- function(bfdata, vars){
  xt <- singles_contingency2(bfdata, vars)
  xr <- chisq.test(xt)$stdres
  p <- mosaic(xt, gp = shading_Friendly, residuals = xr, 
              residuals_type = "Std\nresiduals", labeling = labeling_border(rot_labels = c(90,0,0,90), 
                                                                            just_labels = c("left", "center", "center", "center")))
  return(p)
}

# bfdata = data frame in observation format (0s and 1s for mrcvs)

# returns item response table
bf_mrcv_irtable <- function(bfdata, vars){
  Inum <- bfdata |> select(starts_with(vars[1])) |> ncol()
  Jnum <- bfdata |> select(starts_with(vars[2])) |> ncol()
  bf.ir <- bfdata |> select(starts_with(vars)) |>
    item.response.table(Inum, Jnum)
  return(bf.ir)
}

# bfdata = data frame in observation format (0s and 1s for mrcvs)
# vars = character vector, giving the names of 2 variables to be compared
# test.type = string specifying testing approach (see MRCV::MI.test)
# returns marginal independent test results for vars in vars
bf_mrcv_test <- function(bfdata, vars, test.type = "rs2"){
  Inum <- bfdata |> select(starts_with(vars[1])) |> ncol()
  Jnum <- bfdata |> select(starts_with(vars[2])) |> ncol()
  bf.test <- bfdata |> select(starts_with(vars)) |> 
    MI.test(Inum, Jnum, type = test.type)

}

# bfdata = data frame in observation format (0s and 1s)
# field = string specifying which MR variable to plot intersections of
# min.size, num.intersectinos, keep_empty_groups: parameters for ComplexUpset::upset
# Returns a ComplexUpset plot of the intersectinos for field
bf_mr_upset <- function(bfdata, field, min.size = 0, num.intersections = NULL, keep_empty_groups = FALSE){
  # Working on a subset of rows that are complete
  bf.up <- bfdata |> select(starts_with(field)) |> na.omit() |> 
    mutate(across(everything(), ~ .x == 1)) # converting 0s and 1s to binary
  items <- bf.up |> colnames()
  p <- upset(bf.up, items, name = field, min_size = min.size, 
             n_intersections = num.intersections, keep_empty_groups = keep_empty_groups)
  return(p)
}
