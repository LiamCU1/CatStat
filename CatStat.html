My intention is to plot proportions for the multiple-select and single-choice options in the database.

The multiple-select options are as follows:

  • Sustainable Development Goal(s)

  • Ecosystem(s)

  • Scale

  • Method(s)

  • Output(s)

  • Participants included

  • IPBES Scenario Type(s)

(Note: Theme(s) and Thematic page(s) might also be in this category, but I’m excluding them for now because they are optional)

fields.multi <- c("sdgs", "eco", "scale", "methods", "outputs", "participants", "ipbes.type")
source("1_multiselect_to_binary.R")
bf.multi <- multi_occ(bf, fields.multi, missing = TRUE, shorten = TRUE)

The single-choice fields are:

  • Region

  • Contributor Role

(Note: Although “Country” and “Project year” could also hypothetically be represented as single-choice fields, the possible options are not (usefully) bounded)

fields.single <- c("region", "contributor.role")
source("1_tidy_singlechoice.R")
bf.single <- bf[fields.single] |> tidy_regions()
bf.choice <- cbind(bf.multi, bf.single)

To find the proportion of cases that tick each value, we’ll need different procedures for the multiple-selection and single-choice fields. For the multiple-selection columns, the proportion will be given by the mean.

lowprop <- 0.05 # The threshold for which proportions we consider "low"
bf.multi.prop <- bf.multi |> subset(select = -c(id, short.title)) |>
  sapply(function(x) mean(x, na.rm = TRUE))

For the single-choice columns, the proportion will be given by table(). This function creates a contingency table, which will be relevant later. For now, feeding the function one column simply returns a 1-dimensional vector of counts. For the proportions, we divide that vector by the total count (the length of the original column).

bf.single.prop <- find_singles_prop(bf.single)
bf.prop <- append(bf.multi.prop, bf.single.prop)
bf.low <- bf.prop[bf.prop < lowprop] |> names()
